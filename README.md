# NestIQ — AI-Powered Property Management Platform

A modern, fully responsive landing page for an AI-powered 
property listing and rental management platform built for 
the Indian real estate market.

## Live Demo
[nest-iq.vercel.app](https://nest-iq.vercel.app)

## Built With
- React + TypeScript
- Tailwind CSS
- Vite

## Sections
- Hero with product dashboard mockup
- Problem statement cards
- AI Feature highlights
- How it works (3-step flow)
- Pricing tiers (Starter / Growth / Pro)
- Testimonials
- Footer

## Getting Started

### Prerequisites
- Node.js 18+
- npm

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```
Opens on `http://localhost:5173`

### Build for Production
```bash
npm run build
```

## Project Structure
src/
├── components/ # All section components
├── App.tsx # Main app entry
└── main.tsx # React DOM render

This is a demo project showcasing landing page
